Guide d'utilisation

Synchronisation Gist

1. Configuration initiale

1

Créer le fichier Gist

Va sur gist.github.com, connecte-toi avec ton compte GitHub.

Dans "Filename", écris exactement : force_puissance.json

Dans la zone de texte, écris : {}

Clique sur "Create secret gist".

2

Copier le Gist ID

L'URL de ton Gist ressemble à :
gist.github.com/TON_NOM/a1b2c3d4...

Copie les 32 caractères après le dernier /. C'est ton Gist ID.

3

Créer le Personal Access Token

Va sur github.com/settings/tokens

Clique "Generate new token (classic)".

Nom : Force Puissance App

Expiration : No expiration

Coche uniquement la case gist

Clique "Generate token" et copie immédiatement le token affiché (commence par ghp_). Il ne sera plus visible ensuite.

4

Configurer l'application

Dans les Réglages, section "Synchronisation GitHub Gist", colle le Gist ID et le token dans les champs correspondants. Le voyant passe au vert automatiquement.

⚠️ Conservation du token : Sauvegarde ton token dans un gestionnaire de mots de passe (ou note-le). GitHub ne le montre qu'une seule fois.

2. Récupération d'urgence

Si tu as perdu ton téléphone, ton token et ton Gist ID en même temps — pas de panique. Tes données sont toujours sur GitHub.

1

Retrouver ton Gist ID

Va sur gist.github.com et connecte-toi avec ton compte GitHub.

Tu vois la liste de tous tes Gists. Clique sur celui nommé force_puissance.json.

Copie les 32 caractères dans l'URL — c'est ton Gist ID.

2

Créer un nouveau token

Va sur github.com/settings/tokens.

Si ton ancien token est encore là, tu peux cliquer "Regenerate". Sinon, crée un nouveau token avec uniquement la permission gist.

Installe l'application sur ton nouveau téléphone, ouvre les Réglages et saisis le Gist ID et le nouveau token. Tes données seront récupérées automatiquement depuis le Gist.
